# Homepage-first product outcomes

## First release — homepage
- [x] Build the actual working homepage first for the India-first AI-powered Social Media Automation & Social Link Intelligence SaaS described by the founder, using the existing Democrat.ai project as the codebase. The page must be launch-minded, premium, distinctive and highly interactive; take broad inspiration from Linear, Stripe, Framer and Vercel without copying them or using a generic AI-generated template. Use persuasive natural copy, strong CTAs, elegant typography and sophisticated colors; avoid generic gradients, stock visuals and repetitive cards.
- [ ] Make the entire homepage exceptionally mobile-responsive, accessible, fast and SEO-optimized. Include semantic content, route-appropriate metadata, structured data, sitemap and robots behavior; ensure keyboard access and respect reduced-motion settings without sacrificing the visual experience. The implementation includes semantic/server-rendered content, metadata, structured data, robots/sitemap routes, focus states and reduced-motion handling, but no public site origin is configured in this environment. The canonical/Open Graph absolute URLs are therefore intentionally omitted and the valid sitemap currently contains no URL entries; configure `NEXT_PUBLIC_APP_URL` before treating this outcome as fully complete.
- [x] Show compelling interactive demonstrations of social scheduling, publishing, cross-posting, calendar planning, AI agents, MCP integrations, analytics, captions and automation. Mark all previews as illustrative and never claim an unbuilt backend or integration is live.
- [x] Demonstrate Social Link Intelligence: a supported Instagram Reel, YouTube video, Tweet/X post or other social URL can be represented as becoming AI-readable context, including available metadata, captions, transcripts, comments, engagement signals and analysis. Explain that source availability and platform rules vary; do not simulate or claim a real third-party fetch from the marketing demo.
- [x] Preview how social links are intended to be used from ChatGPT, Claude, Codex and other AI agents through the planned custom MCP server and REST APIs. Make the planned state explicit until implemented.
- [x] Present the planned OAuth account connection experience for Instagram, YouTube, Facebook, X (Twitter), LinkedIn and other social channels without requiring users' own developer API keys. Clearly distinguish planned account connections from the existing application's authentication and from live connected social accounts.
- [x] Show planned analytics, content calendars, AI-assisted captions, competitor analysis and cross-platform automation without suggesting that the current application has started collecting social data or publishing content.
- [x] Explain the India-first business model: freemium, a 30-day free trial with limited credits, affordable paid plans expected around ₹149–₹299 per month, credit-based usage limits on every plan, and no unlimited usage. Do not present estimates as final pricing or imply checkout/trial entitlements are active unless implemented.
- [x] Use clear, honest calls to action. Do not imply early-access notifications, waitlist capture, social-account onboarding or a production trial exist unless implemented.

## Product roadmap — keep outcomes open until delivered
- [ ] Enable social account connection via OAuth for Instagram, YouTube, Facebook, X (Twitter), LinkedIn and other supported platforms, without requiring users to supply their own developer API keys.
- [ ] Build real scheduling, publishing, cross-posting, content automation and calendar workflows across supported platforms.
- [ ] Implement the custom MCP server's Social Link Intelligence: fetch only content, metadata, captions, transcripts, comments and engagement metrics actually available for each supported public URL, subject to platform policy and access.
- [ ] Implement the platform's analytics, AI-assisted captions, competitor analysis and content automation using real connected-account/source data.
- [ ] Provide real MCP and REST APIs for ChatGPT, Claude, Codex and other AI agents.
- [ ] Expand from the homepage to the requested product/site pages: Home, Features, Integrations, Pricing, How It Works, Blog, About, Login, Signup and Dashboard. Existing product/account routes must remain intact; unimplemented pages should not be linked as if they were live.
- [ ] Deliver a freemium 30-day trial with limited credits and paid plans near ₹149–₹299/month. Enforce credit limits on every plan; never offer unlimited usage.
- [ ] Grow toward the founder's initial goal of 500 paying customers, with creators, agencies and AI-automation users in India as the target market.
